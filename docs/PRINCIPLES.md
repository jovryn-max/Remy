# Principles

Concierge30 is concierge medicine for people who have never had concierge medicine. Every decision in this codebase must serve one principle: **friction is the enemy of health engagement**. Someone should be able to walk in, sit down, and 60 seconds later feel like someone competent and kind paid attention to them — without typing a name, downloading an app, or being asked for an email.

## The seven

1. **Tier 0 must be a complete experience.** A user with no phone, no account, no ID gets real value from one visit. Tier 0 is not a teaser for Tier 1+ — it is the product.
2. **The chair is the product, not the room.** Never ask the user to get up or navigate physical space.
3. **Radical simplicity beats clinical comprehensiveness.** When in doubt, remove.
4. **Dignity over data.** Never make the user feel measured, judged, scored, surveilled. No leaderboards, no streaks, no pass/fail colors.
5. **The game is belonging, not points.** No gamification in V1. No streaks, badges, or progress bars, even as "easy wins."
6. **Trust before engagement.** No account prompts, no upsells, no "create a profile to unlock" before visit 3 minimum.
7. **Voice-first, touch-second; camera only the coach can see.** The camera is on, but the feed never reaches a screen, never persists, and never leaves the model that needs it for this moment. The UI says so, in plain words, every visit.

## How to tell if a change violates a principle

- Does it put the user on a path they didn't ask for? (principle 6)
- Does it make the screen more to read? (principle 3, 4)
- Does it introduce a number or color that could feel like a grade? (principle 4, 5)
- Does it treat Tier 0 as incomplete? (principle 1)
- Does it surface the camera feed? (principle 7 — always no)

If the answer to any of those is yes, stop.
