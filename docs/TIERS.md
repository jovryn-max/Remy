# Tiers

Concierge30 delivers meaningfully more as trust deepens — never as a paywall, always as an invitation.

| Tier | What the user gives up | What they get | Status |
|---|---|---|---|
| **Tier 0** | Nothing. No name, no phone, no account. | A full, real visit: greeting, vitals, honest interpretation, three-turn conversation, one dignified next step, printable card. Camera is active but AI-only. | **Day One scope** |
| **Tier 1** | Phone number (no name) | Returning-user recognition on next visit. Optional SMS summary of today's visit. The coach can remember what they said last time. | Move 2 |
| **Tier 2** | First name, consent for care record | A continuous, low-touch record of visits. Coach references their own words back to them over time. Optional hand-off to a human clinician when the user asks. | Move 3 |
| **Tier 3** | Verified identity + insurance (only if user wants it) | CMS-funded care relationship. Prescriptions via partner pharmacy. Shared record with a primary care provider if they choose one. | Move 4 |

## Rules

- Each tier must be independently valuable. A Tier 0 visit can never feel like a trailer for Tier 1.
- No tier asks for anything the user wouldn't happily give at that stage of trust.
- Moving up tiers is always opt-in, always at the user's initiative, never gated behind a mandatory prompt.
- Tier 0 does not become less useful when Tier 1+ exists. Many users will always be Tier 0, and that is fine.

## Day One does NOT implement

- Persistence (no database). Every visit is isolated in memory.
- Phone-number capture or SMS.
- Tier 1+ recognition of returning users.

Those are Move 2 work.
